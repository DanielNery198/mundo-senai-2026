O que é o Canva?

Plataforma online e gratuita de design gráfico, para criar conteúdos visuais de forma simples e intuitiva.

Boa hierarquia visual

  • Fontes, cores e tamanhos adequados.
  • Símbolos e imagens que ajudam a entender o assunto.
  • Setas que organizam o layout.
Clique nas áreas destacadas do mapa para ver a explicação.

O que é o Excel?

Software de planilha eletrônica da Microsoft, parte do pacote Microsoft 365.

Fórmulas e funções

  • Cada célula possui uma localização, como H2.
  • A lógica segue o padrão =SOMA(B3;C3).
  • Uma célula pode exibir o resultado de outras.
Clique nas áreas destacadas da planilha para ver a explicação.
